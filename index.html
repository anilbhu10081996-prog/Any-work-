सुरक्षा: यहाँ मॉड्यूल शॉर्टकट दिखते हैं। Admin और निजी डेटा के अधिकार डेटाबेस/RLS से सत्यापित होने चाहिए।

सुरक्षित कनेक्शन के लिए Supabase आवश्यक है।
Backend जाँच रहा है… Supabase
🛡️ ANY WORK — SUPER ADMIN
User profiles और roles का नियंत्रण

सुरक्षा: यह पैनल केवल Supabase Auth के app_metadata.role=super_admin या app_metadata.roles में super_admin वाले सत्र के लिए खुलेगा। Database RLS भी यही अधिकार लागू करे। भूमिका बदलने और प्रोफ़ाइल हटाने के लिए सुरक्षित server-side Edge Function आवश्यक है; इसलिए इस फ्रंटएंड में सीधे role-change/delete अनुरोध बंद हैं।

यूजर लोड करने के लिए रीफ़्रेश करें।
यूजरईमेलRoleसुरक्षित प्रशासन स्थिति
अभी कोई डेटा लोड नहीं हुआ।

इस इंटरफ़ेस से profiles टेबल का रिकॉर्ड बदला/हटाया जा सकता है, यदि मौजूदा स्कीमा और RLS अनुमति दें। यह Supabase Auth user को delete नहीं करता। Auth user deletion के लिए सुरक्षित Edge Function + service-role secret server पर होना चाहिए—ब्राउज़र में कभी नहीं।
